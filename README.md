# 波日程 · BoSchedule

一款遵循 Material You 设计语言的多平台日程 / 课程表应用，面向大学生与需要管理周期性日程的用户。同一套代码可运行在桌面浏览器、手机浏览器与 PWA 中，并内置局域网同步服务。

- 版本：1.0.1
- 作者：古月波
- 仓库：<https://github.com/GuYueBo2008/BoSchedule>

## 功能特性

### 时间表

- 以周为单位的课程表视图，自动标记当天并高亮当前周
- 支持切换周次，展示每周日期范围
- 支持多个时间表（例如「本科课程」「实习安排」），可随时切换与管理
- 日程按开始 / 结束时间排布，支持 7 种配色
- 点击日程查看详情：桌面端显示右侧抽屉，移动端弹出高斯模糊浮层
- 支持每周、单周、双周、仅在指定周出现，以及起止周范围

### 日程导入

- 手动录入名称、详情、时间段、地点、标签，并可添加多张图片（以 Base64 保存到本地）
- 配置 DeepSeek API Key 后，可从文字或图片中自动识别日程，并将原文 / 原图保存到「来源」字段
- 导入时必须选择目标时间表，避免不同时间表的日程混在一起
- 标签管理：查看每个标签下的日程数量，支持新增、删除；删除时提示受影响的日程并可将它们迁移到其他标签

### 数据同步与管理

- 记录日程的编辑历史
- 导出 / 导入 JSON 日程文件，可按时间表、按标签筛选导出
- 导入时遇到本地不存在的标签，可选择新建标签或映射到已有标签
- 导入冲突时可选择覆盖或忽略
- 局域网同步：先配对，再手动或自动同步，以最后编辑时间为准
- 自动同步时机：应用启动、日程被修改；失败后按设定间隔重试指定次数（默认 15 秒 × 30 次）
- 设备管理：查看已配对设备、手动同步、移除设备
- 同步删除通过墓碑记录（`eventTombstones`）传播，避免已删除的日程被旧设备重新带回

### 分享与主题

- 分享为 Excel（`.xlsx`）或整页图片（`.png`）
- 分享时可选择多个周次与特定标签
- 提供白色、黑色、iOS、PS 四套主题，随时切换

## 快速开始

环境要求：Node.js 20.19+ 或 22.12+。

```bash
npm install

# 开发模式，支持局域网访问
npm run dev        # http://localhost:5173

# 生产构建
npm run build

# 启动生产服务（静态资源 + 局域网同步 API）
npm start          # http://localhost:4173
```

`npm run build` 会先执行 TypeScript 类型检查，再将产物输出到 `dist/`。

## 局域网同步

同步服务随生产服务一起启动，监听 `0.0.0.0:4173`，同一局域网内的手机与电脑可互相访问。

1. 两台设备都打开应用，在「数据同步」页查看本机配对码与本机地址
2. 在另一台设备上输入目标设备的 IP、端口和 6 位配对码完成配对
3. 配对后可手动发起同步，也可在启动和修改日程时自动同步

服务端数据保存在 `~/.boschedule/lan-sync.json`，可通过环境变量 `BOSCHEDULE_DATA_DIR` 修改存储目录。合并规则为按 `updatedAt` 取较新的记录，标签按名称去重，删除通过墓碑时间戳判定。

## 项目结构

```
.
├── src/
│   ├── pages/            # 时间表、日程导入、数据同步三个页面
│   ├── components/       # 日程表单、分享弹窗、设置、时间表管理、通用 UI
│   ├── App.tsx           # 应用状态、页面切换、配对与同步逻辑
│   ├── data.ts           # 默认数据与示例日程
│   ├── types.ts          # 数据模型与设置类型
│   ├── utils.ts          # 周次计算、格式化、下载等工具函数
│   └── styles.css        # 全局样式与主题变量
├── public/               # 图标、Manifest、Service Worker
├── server.mjs            # 生产静态服务与同步 API 入口
├── sync-server.mjs       # 局域网同步接口、配对码与数据合并
└── vite.config.ts        # 开发服务器与同步中间件
```

## 数据说明

- 日程、标签、时间表、设置与历史记录保存在浏览器 `localStorage`（`boschedule-data-v1`）
- DeepSeek API Key 仅保存在本机，不会上传到第三方服务器
- 导入的图片以 Base64 形式保存在本地数据中
- 局域网同步通过配对码鉴权，数据仅在已配对的设备之间传输

## 主题

应用通过 `data-theme` 切换主题，提供：

- `light`：白色 Material You 主题（默认）
- `dark`：黑色主题
- `ios`：iOS 风格
- `ps`：PS 风格
